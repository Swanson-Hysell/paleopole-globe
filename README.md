# PaleopoleGlobe

A lightweight, GPlates-style web app for reconstructing continents from paleomagnetic poles on a globe, written for teaching at the University of Minnesota.

The app is meant to be reused for different problems, each as its own data set ("scenario"). The one included now is **Pole to Pangea**, for ESCI 2201 (Solid Earth Dynamics) Lab 9; its name comes from `meta.title` in `data/lab9.js` and appears next to the app's name in the header and on saved images. The plate IDs, plate pairs, lab-part set-ups and instructor fits are still written into `js/app.js` for this scenario. Moving them into the data file is the next step before a second scenario can be added.

In the Pole to Pangea scenario, each continent (North America with Greenland, Europe with Iberia, South America, Africa) carries its paleomagnetic poles. These are the global apparent polar wander path of Vaes et al. (2023), rotated into each plate's frame with their plate circuit. Students rotate continents together with their poles, so they can:

- put a pole on the spin axis to restore a continent's paleolatitude and orientation;
- see that rotation about the spin axis leaves the pole fit unchanged (longitude is unconstrained);
- fit two continents by making their same-age poles coincide and their shelves fit;
- read when the continents separated from the ages at which the two paths diverge.

How it works for students:

- **Set up for Part B / Part C / All** (top of the panel) shows only the continents, poles and path comparison each part needs. Plates keep their positions when switching. The app opens set up for Part B.
- There are no tool modes. **Drag a continent** to move it (Shift-drag spins it), **drag the ocean** to turn the globe, and **drag a large (focus-age) pole marker** to move its continent by that pole; it snaps onto the North Pole within 2°. A tap or click on a pole or site star shows its details (this replaces hover on touch screens).
- The site readout gives **"Turned since then"**: how the continent has rotated between the position shown and today, which matches the sense of the declination (e.g. D = 336° ↔ 24° counterclockwise).
- Relative rotations are shown as **"axis lat, lon; angle"**, labelled as Euler poles so they are not confused with paleomagnetic poles. Typing a rotation is under *Move → Type a rotation (advanced)*.
- In **Path match**, filled dots are ages whose 95% circles overlap; the summary lists those ages.

It is a static site: HTML, CSS, JavaScript, and one data file. There is no server code, no build step, no tracking and no cookies. A student's name, if typed under *Display*, is kept only in that browser's local storage, so it can be printed on saved images.

## Try it locally

Open `index.html` in a browser; the data are loaded as a script, so this works straight from the disk. To test it the way GitHub Pages serves it:

```bash
cd webapp
python -m http.server 8000
# then open http://localhost:8000
```

## Hosting (GitHub Pages)

This repository, [Swanson-Hysell/paleopole-globe](https://github.com/Swanson-Hysell/paleopole-globe), holds the app exactly as it is served; it is a copy of the `webapp/` folder of the ESCI 2201 Lab 9 build (`Lab 9/2026_build/webapp/` in the course materials), where the data file, the handouts and the screenshots are generated. The Lab 9 handouts point students to `https://swanson-hysell.github.io/paleopole-globe/` (`APP_URL` in that build's `scripts/build_docs.py`).

To turn on the site (once): in the repository on GitHub, **Settings → Pages → Build and deployment → Source: Deploy from a branch**, choose **Branch: `main`**, folder **`/ (root)`**, and click **Save**. After a minute or two the site is live; the Pages settings page shows the address and a "Visit site" button. Open it on a laptop and on a phone before the lab, and try **Save image** and **Copy link**.

To update the app, change it in the course build (regenerate `data/lab9.js` there or edit the code), copy the folder into this clone, then commit and push; Pages redeploys automatically. Before committing, change the `?v=` tag on the script and stylesheet links at the bottom and top of `index.html` (for example to the date), so that browsers load the new files instead of cached copies.

```bash
rsync -a --delete --exclude .git --exclude .DS_Store \
  ".../ESCI_2201/2026_materials/lab_scratch_for_editting/Lab 9/2026_build/webapp/" \
  ~/0000_Github/paleopole-globe/
```

## Instructor tools

Add `?instructor` to the address (for example `https://swanson-hysell.github.io/paleopole-globe/?instructor`) to show three extra buttons under *Instructor tools*:

- snap the selected plate's focus-age pole onto the north pole;
- apply the published Pangea fit (Africa or Europe to North America, or South America to Africa) to the selected plate;
- show the reference reconstruction of all four plates at the focus age (paleomagnetic frame; Africa's longitude is kept as close to today's as possible).

These are useful for demonstrations and for checking student work. They are not secret: a student who adds `?instructor` will find them. The handout questions ask for things students observe and explain, so the buttons do not answer them.

## Sharing a reconstruction

**Copy link** puts the full state (every plate's rotation, the view, the options) in the web address after `#s=`. Opening that link restores the reconstruction, which makes it an easy way for students to send their work to a TA. **Save image** downloads a PNG of the globe with a panel listing the student's name, the focus age, every plate's rotation, the site latitudes and the relative rotations.

## Data and credits

- Reference poles: Vaes, B., van Hinsbergen, D.J.J., van de Lagemaat, S.H.A., et al., 2023, A global apparent polar wander path for the last 320 Ma calculated from site-level paleomagnetic data: *Earth-Science Reviews*, v. 245, 104547, [doi:10.1016/j.earscirev.2023.104547](https://doi.org/10.1016/j.earscirev.2023.104547). The 20 Ma-window path (their Table 3) was rotated into each plate's frame with their plate circuit, reproducing their Table 4 to within 0.05°. Individual igneous poles come from their Table S2. Data and code: [doi:10.5281/zenodo.8356344](https://doi.org/10.5281/zenodo.8356344) (CC BY 4.0).
- Greenland's and Iberia's pre-drift positions (the "Close the Labrador Sea and Bay of Biscay" checkbox in the Plates panel) and the reference Pangea fits come from the same plate circuit (Vaes et al., 2023, Table S1).
- Outlines: [Natural Earth](https://www.naturalearthdata.com) 1:50m countries and lakes, and the 1:10m 1000 m bathymetry contour (public domain).
- Rendering: [d3](https://d3js.org) v7.9.0 (ISC license). The interaction model follows [GPlates](https://www.gplates.org) (Müller et al., 2018, *Geochemistry, Geophysics, Geosystems*, v. 19, p. 2243–2261, [doi:10.1029/2018GC007584](https://doi.org/10.1029/2018GC007584)). PaleopoleGlobe is not affiliated with GPlates.
